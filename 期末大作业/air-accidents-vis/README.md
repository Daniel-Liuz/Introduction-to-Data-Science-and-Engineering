# A&thinsp;A&thinsp;V - Air Accident Visualization

- 此目录为前端服务器根目录，启动前端：

  ```bash
  npm install         # 安装前端依赖
  npm run dev 		# 开发环境 or
  npm start 			# 正式部署
  ```

- 后端根目录为 `./backend`，启动后端：

  ```bash
  cd ./backend		# 进入后端目录
  npm install			# 安装后端依赖
  npm start
  ```

- agent目录为`./ai_service`，启动ai微服务

```bash
cd ./ai_service
python app.py
 ```
